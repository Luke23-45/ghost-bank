\title{Dissecting Exemplar Replay: A Controlled Component Analysis}
\author{}

\begin{document}

\maketitle

\begin{abstract}
Exemplar replay systems combine memory allocation, sample selection,
distillation, classifier design, and prediction rules, making it difficult to
identify which choices govern the accuracy--forgetting trade-off. We conduct a
controlled component study on CIFAR-100 with ten sequential class blocks, a
ResNet-18 backbone, and fixed exemplar memory. The reference system rebuilds
herded exemplars in the current feature space after each task, trains with
replay and old-class distillation, and predicts by nearest-mean exemplars
(NME). Replacing NME with head-logit prediction yields the largest observed
single-component change: average accuracy decreases by $10.38$ percentage
points (pp) and forgetting increases by $32.50$ pp. Replacing herding with
random selection decreases accuracy by $4.83$ pp. Removing distillation leaves
average accuracy nearly unchanged ($-0.21$ pp) while increasing forgetting by
$10.93$ pp, indicating a retention role in this protocol. Reducing memory from
2,000 to 500 exemplars has a larger accuracy effect ($-8.17$ pp) than reducing
retrieval from 64 to 32 samples ($-1.71$ pp). The results identify prediction
rule, exemplar selection, and stored memory as key accuracy determinants, with
distillation serving a distinct retention role. These findings characterize one
dataset, class order, backbone, and resource range.
\end{abstract}
