\section{Introduction}
\label{sec:introduction}

Class-incremental learning requires a model to learn disjoint groups of
classes sequentially and later classify all observed classes without task
identity.  Because prior training data cannot usually be retained in full,
replay stores a bounded set of exemplars.  The relevant constraint is not only
the number of active exemplars: examples selected in an earlier feature space
may become less representative as the model changes.

Replay systems combine several decisions that affect this process.  These
include how the active budget is allocated, when exemplars are refreshed, how
they are selected, how replay enters the loss, and how predictions are made.
When these decisions are bundled, a performance difference can reflect the
memory contents, the training objective, or the readout rather than the
refresh rule itself.

We propose Uniform Herding, a replay method that allocates an active exemplar
budget uniformly across observed classes and refreshes every class after each
task in the current feature representation.  The method uses greedy herding
to construct the active set from a bounded candidate pool.  The active set is
the source of replay; the candidate pool is retained only to provide examples
for later refreshes.  Thus, the active budget and the total retained candidate
storage are distinct quantities.

We compare Uniform Herding with a faithful iCaRL implementation and a static
replay bank on CIFAR-100 split into ten class-incremental tasks.  iCaRL herds a
class when it arrives, preserves the resulting priority order, and truncates
that order as the class quota decreases.  Accordingly, the main comparison is
between complete protocols: the methods also differ in training objective,
readout, and retained candidate storage.  Targeted within-method comparisons
then vary prediction rule, selection rule, distillation, and head geometry,
followed by active-budget and retrieval sweeps.

At the default active budget of 2,000 exemplars and retrieval budget of 64,
Uniform Herding obtains higher mean final accuracy and lower mean forgetting
than both baselines.  Within the proposed configuration, NME prediction and
herding selection yield higher mean final accuracy than their tested
alternatives, while distillation primarily affects retention.  The active-
budget sweep also changes the metrics more than the tested retrieval sweep.

\paragraph{Contributions.}
\begin{itemize}
  \item We define Uniform Herding, a representation-refresh replay method with
  uniform active class allocation and a bounded candidate pool.
  \item We compare it with faithful iCaRL and static-bank baselines at a common
  nominal active budget and retrieval count, while making their objective,
  readout, and storage differences explicit.
  \item We characterize the proposed configuration with targeted within-method
  comparisons and active-budget and retrieval sensitivity analyses.
\end{itemize}
