\section{Conclusion}
\label{sec:conclusion}

This study separates the design choices of a fixed-memory exemplar replay
system. In the evaluated protocol, the prediction rule produces the largest
observed component difference, herding improves both accuracy and retention
relative to random selection, and distillation improves retention with little
change in final average accuracy. Stored memory has a larger observed effect
than the tested retrieval range.

For this protocol, the configuration supported by the measurements allocates
memory across observed classes, rebuilds representative exemplars in the
current feature space, trains with distillation, and predicts with the
corresponding NME prototypes. These findings rank components within the
evaluated protocol. The next step is to run the same matched component analysis
across additional class orders, datasets, architectures, and memory ranges to
test whether that ranking transfers.
