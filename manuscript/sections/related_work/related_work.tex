\section{Related Work}
\label{sec:related-work}

\subsection{Class-Incremental Learning}
\label{subsec:related-cil}

Class-incremental learning has been approached through parameter
regularization, constrained optimization, distillation, and replay.  Elastic
Weight Consolidation and Synaptic Intelligence protect parameters estimated to
be important for prior tasks~\citep{kirkpatrick2017ewc,zenke2017si}.  GEM and
A-GEM instead constrain updates using episodic-memory gradients~\citep{lopezpaz2017gem,chaudhry2019agem}.
Learning without Forgetting preserves old outputs by distillation without
retaining old examples~\citep{li2016lwf}.  Our study belongs to the replay-based setting and asks
how choices inside a fixed-memory replay system affect the resulting
accuracy--forgetting trade-off.

\subsection{Replay and Exemplar Selection}
\label{subsec:related-replay}

Experience replay retains a bounded subset of prior data and interleaves it
with new-task training~\citep{rolnick2019er,chaudhry2019tiny}. iCaRL introduced
a replay recipe: select class exemplars by
herding, replay them during training, and classify with nearest-mean
exemplars~\citep{rebuffi2017icarl}.  The greedy herding rule is designed to
approximate a class mean through selected samples~\citep{welling2009herding}.
Later work treated selection as an optimization problem: maximizing gradient
diversity in the buffer or retrieving samples most likely to be disrupted by
the current update~\citep{aljundi2019gss,aljundi2019mir}.

Our reference shares iCaRL's fixed-total memory semantics and prototype
readout, but rebuilds the selected exemplars for every observed class after
each task using the current representation.  In contrast, iCaRL selects a
class's exemplars when that class first appears and shrinks the set as the
per-class budget drops.  The random-selection ablation therefore
tests selection under the same budget, replay, and readout rather than
comparing unrelated memory systems.

\subsection{Distillation, Classifiers, and Readouts}
\label{subsec:related-readout}

Distillation is paired with replay to preserve old responses.
iCaRL uses output distillation together with exemplar replay and NME
classification~\citep{rebuffi2017icarl}; our temperature-scaled KL objective is
closer in form to the soft-target distillation used by Learning without
Forgetting~\citep{li2016lwf}.  These are related design patterns, not identical
losses.  In particular, iCaRL's original old-class distillation uses sigmoid
binary cross-entropy rather than a temperature-scaled softmax KL term.

Classifier design also affects classifier bias. LUCIR combines a normalized
cosine classifier with a margin-based objective~\citep{hou2019lucir}; BiC and
Weight Aligning correct or align classifier outputs after task
updates~\citep{wu2019bic,zhao2020wa}.
Prototype-based classifiers are an alternative: iCaRL predicts from
exemplar means; FeCAM uses class prototypes with covariance
structure~\citep{rebuffi2017icarl,goswami2023fecam}.  Our matched ablations keep
the representation-learning protocol fixed while separating distillation,
head geometry, exemplar selection, and the final NME versus head-logit
readout.

\subsection{Forgetting and Stability Metrics}
\label{subsec:related-metrics}

The accuracy matrix in continual learning yields average accuracy and
backward transfer, as formalized by GEM~\citep{lopezpaz2017gem}.  Average
forgetting summarizes the decline of each old task from its best observed
accuracy to its final accuracy~\citep{chaudhry2019tiny}.  We report all three
quantities because final average accuracy alone can conceal a configuration
that performs well on the most recent task while degrading older ones. We use
these established measurements as attribution targets in a controlled component
analysis.
